# Project Overview

This repository establishes the foundational architecture for a medical web application and intentionally scopes the work to scaffolding, architecture, and environment setup. The application factory uses a single PostgreSQL database, a React frontend, a NestJS backend, Prisma ORM, JWT authentication, and documentation-first design.

## Product scope

The current implementation does not claim full business feature delivery. Instead, the project provides a durable foundation for healthcare workflows such as patient management, appointments, clinical records, billing, and reporting, with placeholders that can be implemented after approval.

## Core principles

- One centralized relational database.
- Clear separation of frontend and backend concerns.
- RBAC and JWT foundations.
- Observability, validation, and secure configuration.
- Documentation before feature implementation.

## Current status

This scaffold is complete as a project foundation. Full domain-specific business workflows remain pending approval and follow-up implementation.
